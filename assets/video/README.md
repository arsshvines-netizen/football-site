# Videos

Put training videos here, then add the file name in `assets/js/data/videos.js`.

- `drills/`  one clip per drill, named after the drill id (e.g. `gk-01.mp4`)
- `warm-up/` the full warm-up (`full.mp4`) and/or one clip per move

Tips: MP4 (H.264), 720p, under 1 minute, under ~10 MB. No sound needed.
Only film yourself or players whose parents have agreed.
